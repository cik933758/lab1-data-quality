# Отчёт о качестве данных

## 1. Введение

В качестве датасета для анализа были взяты реальные данные из открытого репозитория (Supermarket Sales). Датасет содержит 1000 записей о продажах сети супермаркетов. Признаки включают информацию о филиале, городе, типе клиента, товарной линейке, цене, количестве, сумме чека, дате и оценке обслуживания.

Условный заказчик — руководство сети супермаркетов, заинтересованное в понимании портрета покупателя и улучшении качества сервиса.

С помощью этих данных можно решать такие задачи ИАД:
- сегментация покупателей по типу (Member / Normal) и товарным предпочтениям;
- поиск аномалий (например, подозрительно крупные чеки или ошибки ввода).

## 2. Паспорт датасета

- Строк: 1000
- Столбцов: 17
- Признаки: числовые (Unit price, Quantity, Total), категориальные (City, Customer type, Product line), временной (Date), идентификатор (Invoice ID).

## 3. Основные проблемы качества данных

| № | Тип проблемы | Описание | Риск для анализа | Решение |
|---|---|---|---|---|
| 1 | Пропуски | Отсутствуют | Нет | Не требуются |
| 2 | Дубликаты | Полных дублей и дублей по Invoice ID нет | Нет | Не требуются |
| 3 | Невозможные значения | Отрицательных цен и нулевого количества нет | Нет | Не требуются |
| 4 | Выбросы | В сумме чека (Total) есть крупные покупки (около 1000) | Могут искажать среднее значение | Оставить, так как это реальные дорогие покупки |
| 5 | Грязные категории | Отсутствуют (все города и товары записаны единообразно) | Нет | Не требуются |

## 4. План улучшения качества

**Критично (сделать первым делом):**
1. Данные изначально очень чистые. Критических проблем, требующих немедленного вмешательства, не выявлено.

**Можно отложить:**
2. Для дальнейшего анализа можно дополнительно сгруппировать клиентов по возрасту (создав категории из числового признака).
3. Выбросы в сумме чека можно оставить, так как они отражают реальные дорогие покупки, либо ограничить их для специфических моделей.

## 5. Краткое резюме

В ходе работы я научился проводить первичный аудит качества реальных данных из открытого репозитория: искать пропуски, дубликаты, аномальные значения и выбросы, а также строить базовые визуализации.

Главные выводы по данным: датасет очень качественный и чистый, не требует серьезной предварительной обработки. При дальнейшем ИАД (например, для сегментации) стоит обратить внимание на обработку крупных выбросов в сумме чека, чтобы они не искажали модель.
