# Лабораторная работа №1 — Первичное исследование и оценка качества данных

## Что это
Анализ синтетического датасета заказов интернет-магазина (605 строк, 9 признаков).

## Структура
- `notebooks/01_data_understanding.ipynb` — анализ данных
- `data/dataset.csv` — датасет
- `report/quality_report.md` — текстовый отчёт
- `generate_data.py` — скрипт генерации датасета

## Как запустить
1. Установить зависимости: `python -m pip install pandas numpy matplotlib seaborn jupyter`
2. Запустить Jupyter: `python -m jupyter notebook`
3. Открыть `notebooks/01_data_understanding.ipynb` и выполнить **Cell → Run All**.
